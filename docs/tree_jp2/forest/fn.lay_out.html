pub fn lay_out(arena: Arena, root: NodeId) -> Arena
Expand description

Places every node of arena, depth running left to right.

The layout is what the module’s last section describes; this is only where it is asked for. The arena goes over and comes back rather than being borrowed, so a caller cannot look at it half laid out: the arena it had is gone, and the one it gets back is finished.
