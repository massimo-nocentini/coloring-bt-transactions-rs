Expand description

A place colors live, and everything the driver does to them.

A ColorStore::Color is a handle whose meaning is private to the store that made it; handing one to a different store is a bug this trait cannot prevent. Handles are owned — ColorStore::release each exactly once — which is why Color is deliberately not Copy.

Required Associated Constants§

Source

const WEIGHTED: bool

Whether ColorStore::combine and ColorStore::scale do anything with the weights they are handed.

A constant rather than a method so the driver can skip working the weights out at all for stores that ignore them: run is instantiated per backend, so if S::WEIGHTED folds away at compile time and the unweighted path costs exactly what it did before weights existed.

Source

fn combine( &mut self, a: &Self::Color, wa: f64, b: &Self::Color, wb: f64, ) -> Self::Color

wa * a + wb * b: union of the two supports, with the weights of each side scaled on the way through and matching blocks summed.

Borrows both operands and leaves them untouched. Stores with ColorStore::WEIGHTED false ignore wa and wb and answer the plain union, which is the same thing when every weight is 1 and the driver only ever asks for ior.

Source

fn scale(&mut self, color: &Self::Color, w: f64) -> Self::Color

Every weight multiplied by w. Ignored, and equivalent to ColorStore::share, when ColorStore::WEIGHTED is false.

Source

fn share(&mut self, color: &Self::Color) -> Self::Color

A second owned handle on the same color. A copy for RingStore, a refcount bump for a sharing store; callers should assume it is expensive.

Source

fn release(&mut self, color: Self::Color)

Give a handle back. It must not be used again.

Source

fn for_each_term(&self, color: &Self::Color, f: impl FnMut(usize, f64))

Visit the blocks in decreasing order as (exponent, coefficient) pairs.

The coefficient is an f64 whichever store this is. For the unweighted ones it is always exactly 1.0 and the driver prints it as the integer the Scheme prints; carrying it as a float costs nothing there and saves the trait an associated type that only one backend would use.

Source

fn usage(&self) -> (usize, usize)

(live, committed) in whatever unit the store counts, for --stats, with ColorStore::usage_labels naming them. The backends count different things, so these compare across a run, not across backends.

Source

fn audit(&self, live: &mut dyn Iterator<Item = &Self::Color>) -> String

One line saying whether everything the store thinks is live is reachable from the colors the driver still holds. A leak is invisible in the output — a leaked color is still a correct color — so it needs its own check.

Provided Methods§

Source

fn observe(&mut self, _color: &Self::Color)

Offered each finished color, so a store with an invariant can watch it.

Only called under --stats, because checking one generally means a pass over the color and that is not worth doing on every record of a real run. The default does nothing.
