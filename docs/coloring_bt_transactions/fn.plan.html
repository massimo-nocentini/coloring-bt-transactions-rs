Work out where the records come from and where the colors go.

The two are settled together because a picture states its size before its first sample, so both of its dimensions have to be read off the records before the first row can be written, and that costs the input a rewind. The error is the message to print, since every one of these is a complaint about the command line rather than something to recover from.
