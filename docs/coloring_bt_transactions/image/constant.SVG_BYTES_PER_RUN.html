What one run costs as a stroke, near enough for the note --stats prints about the format that was not chosen.

Measured rather than counted up from the grammar: m-4930 1h6 is ten bytes and a run at the start of a row is six, and across four synthetic runs of very different shapes the mean came out between 6.3 and 8.3. It stays that short however big the picture gets because every move but the first says how far the pen went rather than where it landed, and a step is a few digits even when the coordinates are seven.
