pub fn scale_add_into(dst: &mut [f64], a: &[f64], fa: f64, b: &[f64], fb: f64)
Expand description

dst[k] = a[k] * fa + b[k] * fb, for as many elements as all three hold.

The blocks that both colors carry, once the merge has lined them up. Same reasoning as scale_into: written plainly so the vectoriser can take it, and it fuses into a multiply-add on targets that have one.
