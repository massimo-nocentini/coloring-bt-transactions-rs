digit_run on NEON.

A byte is a digit exactly when b - b'0' is 9 or less as an unsigned byte — one subtract and one compare, no range pair. Locating the first failure is the only fiddly part: aarch64 has no movemask, so the usual stand-in is vshrn by 4, which narrows the 16 lanes of 0x00/0xFF into 16 nibbles of a single u64. The first non-digit is then at nibble trailing_zeros() / 4.
