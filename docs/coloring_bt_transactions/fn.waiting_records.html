pub(crate) fn waiting_records(source: Option<&mut File>) -> u64
Expand description

How many bytes of records are still waiting on standard input, for the one refusal that is about what was not asked for.

--matrix replaces the records, so a run that is given both has a redirect nothing will read; plan refuses that, and this is the number the refusal names. Answering it costs no read and cannot block: the handle is already dup’d and already positioned, so a regular file’s remainder is arithmetic on its metadata.

Zero for everything else, and that is the point of the is_file test rather than a length test alone. A pipe never reaches here – rewindable_stdin hands back nothing for one – and < /dev/null is a character device, whose length is a fiction; both of those are the shapes an empty redirect takes, and neither is somebody handing this run records it asked to ignore.
