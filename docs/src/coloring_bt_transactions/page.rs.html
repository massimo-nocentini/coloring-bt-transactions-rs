1//! # The same picture, on a page
2//!
3//! [`image`](crate::image) draws one pixel per (transaction, block) pair, which
4//! is the whole answer and nothing but it — and on a real run that is a picture
5//! no reader will open.  The million records the driver stops at, over the
6//! hundred and thirty-five thousand blocks they reach back through, come to
7//! 135,659 x 1,000,001: a hundred and thirty-five *gigapixels*, 1.8 GB of PNG,
8//! and every decoder that meets it tries to allocate the raster and gives up.
9//! The file is well formed; it is simply larger than the thing it was drawn to
10//! be looked at with.
11//!
12//! So this draws the same answer at a size a page can hold.  A canvas of at most
13//! [`DEFAULT_PAGE`] cells each way, one PDF page of it, and the picture's pixels
14//! folded into the cells that cover them.  Nothing else changes: the rows are
15//! still the records in the order they arrive, the columns are still block ids
16//! counting up from 0, and `--bin` still folds transactions together before any
17//! of this sees them.
18//!
19//! ## What a cell says
20//!
21//! A cell covers a rectangle of the full picture — some span of block ids by
22//! some span of records — and it is shaded by how much of that rectangle is
23//! inked.  Coverage is counted exactly: the spans are the ones the cell actually
24//! covers (they differ by one from cell to cell when the picture does not divide
25//! evenly), a block inked twice in one row counts once because a row is a union,
26//! and a row the records never reached counts as blank rather than as absent.
27//!
28//! A pixel need not be all ink or none, and under `--weighted` it is not: it
29//! carries the share of the transaction's value that came through the block, and
30//! a cell adds up the shares rather than counting the pixels.  Unweighted every
31//! share is 1, so the sum *is* the count and this is the same page it always
32//! was; weighted, a cell of the same shape comes out lighter, because the ink in
33//! it genuinely is.
34//!
35//! Coverage is not shade, though.  A colour of a thousand blocks in a cell
36//! eighty-five blocks by six hundred records is a coverage of a few percent, and
37//! a few percent of black on white is white as far as the eye is concerned.  So
38//! the shade is `coverage^(1/TONE)` — a plain gamma curve, which lifts sparse
39//! ink into something visible while keeping the ordering, so a darker cell still
40//! means more ink than a lighter one.  What it does *not* mean is twice the ink
41//! for twice the darkness; read the page for shape, and the text output or a
42//! `--blocks`-narrowed PNG for quantities.  It is
43//! [`image::shade`](crate::image::shade), which is the curve a weighted *pixel*
44//! is drawn with as well.
45//!
46//! ## Cells are not square, on purpose
47//!
48//! Each axis is capped on its own, so a picture larger than the page both ways
49//! fills the page both ways.  A cell of the 135,659 x 1,000,001 run above is
50//! then 133 blocks by 977 records, which is not a square of anything.
51//!
52//! That is the right distortion to take here, because the two axes are not the
53//! same kind of quantity to begin with — one is a block id and the other is a
54//! position in the record stream — so there is no aspect ratio to preserve.
55//! Scaling both by the smaller factor instead would draw that run as a strip 135
56//! cells wide down a page a thousand tall, which throws away the axis with the
57//! most in it.  `--bin` already rescales one axis and not the other for the same
58//! reason.
59//!
60//! ## Why a page rather than a bigger raster
61//!
62//! Cairo measures a page in points, and this gives it one point per cell, the
63//! way the viewers' `e` gives it one point per window pixel: a 1024-cell canvas
64//! becomes a 1024-point page, a big sheet at the shape of the drawing.  What
65//! goes on the page is a single greyscale image at exactly that size — one
66//! device pixel per point — so the reader does no resampling and the file is a
67//! few hundred kilobytes whatever the picture behind it was.
68//!
69//! A vector page was the other option and is the wrong one at this size: a
70//! rectangle per inked cell is a million paths, which is a slower page and a
71//! larger file than the image, and buys sharpness a picture of *coverage* has no
72//! use for.
73//!
74//! ## What it costs to draw
75//!
76//! One `f32` per cell — four megabytes at the default page, whatever the
77//! picture — plus a bit and a weight per column for the row being built, so that
78//! a bin's transactions union rather than accumulate.  Both dimensions are still settled
79//! before the first record, because the canvas has to be allocated; that is the
80//! same rewind-and-count pass a PNG needs, and `main`'s `survey` is the same
81//! walk for both.

97/// How many cells the canvas gets each way, and so how many points the page is
98/// each way.
99///
100/// 1024 points is a fourteen-inch sheet: larger than anything one would print,
101/// which is what one wants from a page that is being read on a screen and zoomed
102/// into.  Every cell of it is a rectangle of the picture, so more cells is more
103/// of the picture told apart and not more paper.
104pub const DEFAULT_PAGE: usize = 1024;
105
106/// The most cells a canvas will take each way: 14,400.
107///
108/// Two reasons that happen to be the same number.  A PDF states its page size in
109/// `/MediaBox`, in points, and readers hold it to 200 inches — 14,400 points, and
110/// one point is one cell here, so a larger canvas is a page that is out of spec
111/// whatever cairo will happily write.  And a canvas costs four bytes a cell
112/// while the run is going, so 14,400 each way is already 830 MB of counting; a
113/// ceiling an order of magnitude higher would be one nothing could allocate
114/// behind.
115///
116/// Nothing the driver asks for comes near it — it draws at [`DEFAULT_PAGE`] —
117/// but a `Writer` is told its canvas, so the ceiling is stated where the canvas
118/// is taken.
119pub const MAX_PAGE: usize = 14_400;

121/// A picture being drawn a transaction at a time, onto a canvas of fixed size.
122///
123/// The interface is [`image::Writer`](crate::image::Writer)'s, and deliberately:
124/// the driver's `Output` holds one or the other and the loop that feeds them
125/// does not know which.
126pub struct Writer {
127    /// Where the page goes.  Held rather than opened, since the surface is not
128    /// started until [`Writer::finish`] has the counts to draw.
129    path: String,
130    /// Columns of the full picture, i.e. how many block ids it has room for.
131    width: usize,
132    /// Rows of the full picture: the records, divided by the bin.
133    height: usize,
134    /// Transactions to a row, exactly as the PNG means it.
135    bin: usize,
136    /// Cells across the canvas, at most `width`.
137    across: usize,
138    /// Cells down it, at most `height`.
139    down: usize,
140    /// `block -> cell column`, so that inking a block is a load rather than a
141    /// division.  A colour's terms are the innermost loop of the whole program
142    /// and there are billions of them in a run.
143    column_of: Vec<u32>,
144    /// How much ink the picture pixels a cell covers came to, `across * down` of
145    /// them, row major.  A pixel's ink is its weight, which is 1 for every term
146    /// an unweighted colour has, so this is a count of inked pixels there.
147    counts: Vec<f32>,
148    /// Where the row being built writes: `cell row * across`, recomputed once a
149    /// row rather than once a term.
150    band: usize,
151    /// Which blocks the row being built has already inked, one bit each, so that
152    /// a bin's transactions union.  All 0s outside `..dirty`, which is what lets
153    /// a closed row be blanked by clearing a prefix.
154    row: Vec<u8>,
155    /// How much ink each of those blocks has in the row so far, one per column.
156    ///
157    /// Only read where `row` says the block is inked, which is why it is never
158    /// blanked: a stale weight is unreachable until the bit beside it is set
159    /// again, and setting it writes the weight in the same breath.
160    weights: Vec<f32>,
161    dirty: usize,
162    /// Transactions drawn into the row being built, always below `bin`.
163    pending: usize,
164    /// Rows finished so far, at most `height`.
165    rows: usize,
166    /// The first block id seen that the picture has no column for, if any.
167    escaped: Option<usize>,
168    /// What every cell's ink is multiplied by before shading; see
169    /// [`Writer::set_gain`].
170    gain: f32,
171}

173impl Writer {
174    /// Open a page at `path` for a picture `width` columns by `height` rows,
175    /// with `bin` transactions to the row, folded onto a canvas of at most
176    /// `page` cells each way.
177    ///
178    /// Nothing is written here — a PDF is not a stream of scanlines and the page
179    /// is drawn in one go at the end — but the canvas is allocated, which is why
180    /// both dimensions are still wanted up front.
181    pub fn new(
182        path: &str,
183        width: usize,
184        height: usize,
185        bin: usize,
186        page: usize,
187    ) -> io::Result<Self> {
188        assert!(bin > 0, "a row has to stand for at least one transaction");
189        assert!(page > 0, "a page of no cells has nothing to draw in");
190        if page > MAX_PAGE {
191            return Err(io::Error::other(format!(
192                "a canvas {} cells each way is past the ceiling of {}",
193                page, MAX_PAGE
194            )));
195        }
196        if width == 0 || height == 0 {
197            return Err(io::Error::other(
198                "an image needs a column and a row, and this one has none",
199            ));
200        }
201
202        // Each axis capped on its own -- see the module docs for why the shape
203        // of the picture is not preserved.  Never enlarged: a picture smaller
204        // than the page is drawn at one cell per pixel and stays exact.
205        let across = width.min(page);
206        let down = height.min(page);
207
208        let column_of = (0..width).map(|b| (b * across / width) as u32).collect();
209        let cells = across.checked_mul(down).ok_or_else(|| {
210            io::Error::other(format!(
211                "a {} x {} canvas is more than can be held",
212                across, down
213            ))
214        })?;
215
216        Ok(Writer {
217            path: path.to_string(),
218            width,
219            height,
220            bin,
221            across,
222            down,
223            column_of,
224            counts: vec![0.0; cells],
225            band: 0,
226            row: vec![0; width.div_ceil(8)],
227            weights: vec![0.0; width],
228            dirty: 0,
229            pending: 0,
230            rows: 0,
231            escaped: None,
232            gain: 1.0,
233        })
234    }
235
236    /// Multiplies every cell's ink by `gain` before it is shaded, clamped at
237    /// full coverage.
238    ///
239    /// The shade curve lifts sparse ink, and for the unweighted picture that
240    /// is enough.  A *weighted* colour's mass, though, is a distribution over
241    /// its whole width --- a cell of a hundred columns holds around a
242    /// hundredth of one row's value however the row is drawn --- so a folded
243    /// weighted page is genuinely, and uselessly, near white.  Gain is the
244    /// declared correction: the shade stands for `gain` times the ink, the
245    /// caller says how much, and a caption that quotes it is telling the
246    /// truth about the picture.  At 1 nothing changes.
247    pub fn set_gain(&mut self, gain: f64) {
248        self.gain = gain as f32;
249    }
250
251    /// Ink the pixel for `block` in the row being built, with `weight` as its
252    /// coefficient — 1 for every term an unweighted colour has, and the share of
253    /// the transaction's value that came through the block for a weighted one.
254    ///
255    /// A block already inked in this row is not counted again: a row is the
256    /// union of the transactions binned into it, so the second transaction to
257    /// reach a block adds nothing to the row and must add nothing to the cell.
258    /// Where the second one is *heavier*, the row takes the difference and no
259    /// more — the union of two weighted pixels is the darker of them, which is
260    /// the same rule as "counted once" when every weight is 1.
261    ///
262    /// A block the picture has no column for is remembered rather than reported,
263    /// for the reason [`image::Writer::set`](crate::image::Writer::set) gives:
264    /// this runs inside the store's walk over the colour's terms, which has
265    /// nowhere to put an error.
266    #[inline]
267    pub fn set(&mut self, block: usize, weight: f64) {
268        if block >= self.width {
269            self.escaped.get_or_insert(block);
270            return;
271        }
272        let byte = block / 8;
273        let bit = 0x80 >> (block % 8);
274        let weight = weight as f32;
275        // Nothing there yet is nothing to keep: the bit is what says whether the
276        // weight beside it belongs to this row at all.
277        let held = if self.row[byte] & bit != 0 {
278            self.weights[block]
279        } else {
280            self.row[byte] |= bit;
281            if byte >= self.dirty {
282                self.dirty = byte + 1;
283            }
284            self.weights[block] = 0.0;
285            0.0
286        };
287        if weight <= held {
288            return;
289        }
290        self.weights[block] = weight;
291        self.counts[self.band + self.column_of[block] as usize] += weight - held;
292    }

294    /// Finish one transaction, closing the row if it completes a bin.
295    pub fn end_transaction(&mut self) -> io::Result<()> {
296        if let Some(block) = self.escaped {
297            return Err(io::Error::new(
298                io::ErrorKind::InvalidData,
299                format!(
300                    "block {} has no column in a {}-column picture; \
301                     rerun with --blocks {} or more",
302                    block,
303                    self.width,
304                    block + 1
305                ),
306            ));
307        }
308        self.pending += 1;
309        if self.pending == self.bin {
310            self.end_row()?;
311        }
312        Ok(())
313    }
314
315    /// Close the row being built and start the next, which may or may not be in
316    /// the same band of cells.
317    fn end_row(&mut self) -> io::Result<()> {
318        if self.rows == self.height {
319            return Err(io::Error::new(
320                io::ErrorKind::InvalidData,
321                format!(
322                    "the picture was opened {} rows tall and the records have filled it; \
323                     the count they were measured by is not the count they are arriving at",
324                    self.height
325                ),
326            ));
327        }
328        // Bits are only ever set below `dirty`, so that prefix is the only part
329        // of the row that can have gone dark -- see `image::Writer::end_row` for
330        // why that is the difference it is.
331        self.row[..self.dirty].fill(0);
332        self.dirty = 0;
333        self.pending = 0;
334        self.rows += 1;
335        self.band = self.rows * self.down / self.height * self.across;
336        Ok(())
337    }

339    /// `(columns, rows)` of the full picture, which is what it would be as a
340    /// PNG.
341    pub fn dimensions(&self) -> (usize, usize) {
342        (self.width, self.height)
343    }
344
345    /// `(cells across, cells down)`, which is also the page in points.
346    pub fn canvas(&self) -> (usize, usize) {
347        (self.across, self.down)
348    }

350    /// How many transactions a row of the picture stands for, which is `--bin`.
351    ///
352    /// Only the window asks: a page says nothing about itself, while the panel
353    /// turns a row back into the record it started at.
354    #[cfg(feature = "gui")]
355    pub fn bin(&self) -> usize {
356        self.bin
357    }
358
359    /// Close the row in hand, if the records stopped part way through one.
360    ///
361    /// A bin that never filled up is still a row: the run does not owe the
362    /// picture a whole bin's worth of transactions at the end of the records.
363    /// Separate from [`Writer::finish`] because the window closes the picture
364    /// without writing one.
365    pub fn close(&mut self) -> io::Result<()> {
366        if self.pending > 0 {
367            self.end_row()?;
368        }
369        Ok(())
370    }

372    /// The canvas as ink: one byte a cell, row major, [`shade`]d from the ink in
373    /// them.
374    ///
375    /// 255 is a cell that is all ink and 0 is one that is all paper, so this is
376    /// a *mask* rather than a picture — whatever draws it chooses the colour,
377    /// and both things that draw it choose black.
378    ///
379    /// Rows the records never reached are shaded by the ink that *is* in them
380    /// over the whole rectangle they stand for, blank rows included.  That is
381    /// the honest reading of a picture opened taller than the records filled.
382    pub fn shades(&self) -> Vec<u8> {
383        let mut out = vec![0u8; self.across * self.down];
384        for cy in 0..self.down {
385            // How many picture rows and columns this row of cells covers.  They
386            // differ by one across the canvas whenever the picture does not
387            // divide evenly, and a denominator that ignored that would shade the
388            // odd cell wrong.
389            let tall = span(self.height, self.down, cy);
390            let band = cy * self.across;
391            for cx in 0..self.across {
392                let ink = self.counts[band + cx];
393                if ink <= 0.0 {
394                    continue;
395                }
396                let area = span(self.width, self.across, cx) * tall;
397                // Gain lifts the ink and full coverage caps it: a cell cannot
398                // claim to be more than all ink.
399                out[band + cx] = shade((ink * self.gain).min(area as f32), area);
400            }
401        }
402        out
403    }

405    /// Close the picture, shade every cell, and write the canvas as an 8-bit
406    /// greyscale PNG: the same drawing `--pdf` puts on a page, as a raster any
407    /// build can write --- no Cairo, no feature, nothing installed.
408    ///
409    /// The shades are a mask (255 is ink), a PNG sample is a brightness (255
410    /// is paper), so the byte is flipped on the way through; everything else
411    /// --- the fold, the gamma, the cell spans --- is exactly the page's.
412    pub fn finish_png(mut self) -> io::Result<()> {
413        self.close()?;
414        let mut samples = self.shades();
415        for s in samples.iter_mut() {
416            *s = 255 - *s;
417        }
418        write_png_gray8(&self.path, self.across, self.down, &samples)
419    }
420
421    /// Close the picture, shade every cell, and write the page.
422    #[cfg(feature = "pdf")]
423    pub fn finish(mut self) -> io::Result<()> {
424        self.close()?;
425        let ink = mask(&self.shades(), self.across, self.down)?;
426
427        // One point a cell, the way the viewers' export gives one point a window
428        // pixel.
429        let page = PdfSurface::new(self.across as f64, self.down as f64, &self.path).map_err(
430            |e| io::Error::other(format!("{}: the page could not be started ({})", self.path, e)),
431        )?;
432        {
433            let cr = Context::new(&page).map_err(|e| {
434                io::Error::other(format!("{}: nothing to draw with ({})", self.path, e))
435            })?;
436            paper(&cr).map_err(|e| {
437                io::Error::other(format!("{}: the paper could not be laid ({})", self.path, e))
438            })?;
439            stamp(&cr, &ink, 0.0, 0.0, 1.0).map_err(|e| {
440                io::Error::other(format!("{}: the ink could not be laid ({})", self.path, e))
441            })?;
442        }
443        page.finish();
444        Ok(())
445    }
446}

448/// [`Writer::shades`] as an A8 surface, which is the form Cairo will paint.
449///
450/// A copy rather than a view because an image surface pads its rows out to a
451/// multiple of four bytes and a canvas of shades does not; `stride` is where
452/// that padding is accounted for, and it is the only reason this is a loop.
453#[cfg(feature = "pdf")]
454pub fn mask(shades: &[u8], across: usize, down: usize) -> io::Result<ImageSurface> {
455    debug_assert_eq!(shades.len(), across * down);
456    let mut ink = ImageSurface::create(Format::A8, across as i32, down as i32)
457        .map_err(|e| io::Error::other(format!("the canvas could not be made ({})", e)))?;
458    {
459        let stride = ink.stride() as usize;
460        let mut data = ink
461            .data()
462            .map_err(|e| io::Error::other(format!("the canvas could not be drawn on ({})", e)))?;
463        for cy in 0..down {
464            let line = cy * stride;
465            let band = cy * across;
466            data[line..line + across].copy_from_slice(&shades[band..band + across]);
467        }
468    }
469    Ok(ink)
470}

472/// Covers whatever `cr` draws on in paper.
473///
474/// A PDF page is transparent until something covers it, and a picture of black
475/// ink on nothing is a picture of black ink on whatever the reader happens to
476/// put behind it.  A window has the same hole in it, filled the same way.
477#[cfg(feature = "pdf")]
478pub fn paper(cr: &Context) -> Result<(), cairo::Error> {
479    cr.set_source_rgb(1.0, 1.0, 1.0);
480    cr.paint()
481}

483/// Draws the canvas in black, with its top-left corner at `(x, y)` and each cell
484/// `scale` units across.
485///
486/// A cell is a *sample* here — a rectangle of the picture, painted the shade of
487/// how much of it is inked — which is what a cell has to be while it is around a
488/// pixel across.  Once there is room for a cell to be a shape rather than a
489/// sample the window draws it as one instead; see `window`'s own docs for where
490/// the two change over and why the page never reaches it.
491#[cfg(feature = "pdf")]
492pub fn stamp(
493    cr: &Context,
494    ink: &ImageSurface,
495    x: f64,
496    y: f64,
497    scale: f64,
498) -> Result<(), cairo::Error> {
499    cr.save()?;
500    cr.translate(x, y);
501    cr.scale(scale, scale);
502    cr.set_source_rgb(0.0, 0.0, 0.0);
503
504    let mask = cairo::SurfacePattern::create(ink);
505    // A cell blown up past a pixel is a cell and should look like one: at a
506    // pixel a cell and above, the samples are drawn as the squares they are,
507    // rather than smeared into each other by an interpolation that invents
508    // coverage the records never had.  Shrinking is the other way round — there
509    // the neighbours have to be averaged or most of them are simply not looked
510    // at, which is how a picture loses the thin diagonal that is the whole shape
511    // of it.
512    mask.set_filter(if scale >= 1.0 {
513        cairo::Filter::Nearest
514    } else {
515        cairo::Filter::Good
516    });
517    cr.mask(&mask)?;
518
519    cr.restore()
520}

522/// How much of a cell's black gets through, given that the `area` picture pixels
523/// it covers came to `ink` between them.
524///
525/// An A8 surface is a mask, so 255 is the ink and 0 is the paper, which is the
526/// way round [`image::shade`] answers; the curve and what it does to the low end
527/// are written down there.  A cell every pixel of which is fully inked is the
528/// ink itself, and one with nothing in it is paper.
529fn shade(ink: f32, area: usize) -> u8 {
530    debug_assert!(
531        ink as f64 <= area as f64 + 1e-3,
532        "a cell cannot hold more ink than it has room for"
533    );
534    image::shade(ink as f64 / area as f64)
535}

537/// How many of `total` things fall in cell `i` of `cells`, under the mapping
538/// `thing -> thing * cells / total` that [`Writer::set`] and [`Writer::end_row`]
539/// place things by.
540///
541/// The inverse of that floor, counted rather than approximated by `total /
542/// cells`: `i` holds the things from `ceil(i * total / cells)` up to but not
543/// including `ceil((i + 1) * total / cells)`.  With `cells <= total` — which is
544/// how the canvas is sized — that is never empty, so it is never a denominator
545/// of zero.
546fn span(total: usize, cells: usize, i: usize) -> usize {
547    ((i + 1) * total).div_ceil(cells) - (i * total).div_ceil(cells)
548}

550/// Writes `samples` --- one byte a pixel, row major, 255 the brightest --- to
551/// `path` as an 8-bit greyscale PNG.
552///
553/// A canvas is at most [`MAX_PAGE`] cells each way, so unlike
554/// [`image`](crate::image)'s writer this neither streams nor filters: the
555/// whole raster is deflated in one go behind a filter byte of 0 per row, which
556/// for a picture this size is bytes nobody will miss.  The chunk machinery ---
557/// length, type, CRC --- is the whole of what PNG asks for.
558fn write_png_gray8(path: &str, width: usize, height: usize, samples: &[u8]) -> io::Result<()> {
559    debug_assert_eq!(samples.len(), width * height);
560
561    let mut raw = Vec::with_capacity(samples.len() + height);
562    for row in samples.chunks(width) {
563        raw.push(0u8); // filter: none
564        raw.extend_from_slice(row);
565    }
566    let mut deflate = ZlibEncoder::new(Vec::new(), Compression::default());
567    deflate.write_all(&raw)?;
568    let idat = deflate.finish()?;
569
570    let chunk = |out: &mut Vec<u8>, kind: &[u8; 4], body: &[u8]| {
571        out.extend_from_slice(&(body.len() as u32).to_be_bytes());
572        out.extend_from_slice(kind);
573        out.extend_from_slice(body);
574        let mut crc = Crc::new();
575        crc.update(kind);
576        crc.update(body);
577        out.extend_from_slice(&crc.sum().to_be_bytes());
578    };
579
580    let mut ihdr = Vec::with_capacity(13);
581    ihdr.extend_from_slice(&(width as u32).to_be_bytes());
582    ihdr.extend_from_slice(&(height as u32).to_be_bytes());
583    // Bit depth 8, colour type 0 (greyscale), deflate, no filter set, no
584    // interlace.
585    ihdr.extend_from_slice(&[8, 0, 0, 0, 0]);
586
587    let mut out = Vec::with_capacity(idat.len() + 128);
588    out.extend_from_slice(b"\x89PNG\r\n\x1a\n");
589    chunk(&mut out, b"IHDR", &ihdr);
590    chunk(&mut out, b"IDAT", &idat);
591    chunk(&mut out, b"IEND", &[]);
592    std::fs::write(path, &out)
593}

599    /// Every deflated stream in `bytes`, inflated and run together as text.
600    ///
601    /// The one place a PDF says how big its page is is `/MediaBox`, and cairo
602    /// writes the page dictionary into a compressed `/ObjStm`: it is not there
603    /// to be read off the file.  Streams that are not text — the picture itself,
604    /// most of all — fail to come back as UTF-8 and are passed over, which is
605    /// the filter as well as the decoder.
606    ///
607    /// `window`'s tests ask the same question of the page `e` writes, which is
608    /// why this is not private to this one.
609    pub fn inflated(bytes: &[u8]) -> String {
610        use flate2::read::ZlibDecoder;
611        use std::io::Read;
612
613        fn find(hay: &[u8], needle: &[u8]) -> Option<usize> {
614            hay.windows(needle.len()).position(|w| w == needle)
615        }
616
617        let mut out = String::new();
618        let mut at = 0;
619        while let Some(found) = find(&bytes[at..], b"stream") {
620            // The keyword is followed by an end-of-line, which PDF allows to be
621            // either a newline or a carriage return and one.
622            let head = at + found + b"stream".len();
623            let start = match bytes.get(head) {
624                Some(b'\r') => head + 2,
625                _ => head + 1,
626            };
627            let Some(found) = find(&bytes[start..], b"endstream") else {
628                break;
629            };
630            let end = start + found;
631            let mut text = String::new();
632            if ZlibDecoder::new(&bytes[start..end])
633                .read_to_string(&mut text)
634                .is_ok()
635            {
636                out.push_str(&text);
637            }
638            // Past the closing keyword, whose own `stream` would otherwise be
639            // the next thing found.
640            at = end + b"endstream".len();
641        }
642        out
643    }

666    /// pixel of which is inked is the ink itself.  Between them it climbs and

668    /// visible grey rather than a rounding error.

672        assert_eq!(shade(400.0, 400), 255);
673        assert_eq!(shade(4.0, 400), 31); // one percent of the cell, twelve of the ink

675        let mut last = 0;

677            let now = shade(count as f32, 400);
678            assert!(now >= last, "{count} of 400 shaded {now} after {last}");

693    /// A path for a writer that is never going to be finished.  Nothing is
694    /// created before `finish`, so the tests about the counts touch no disk at

698    /// Draw `colors` -- one per transaction -- and hand back the writer's counts
699    /// before they are shaded, which is the part worth asserting about.
700    fn drawn(width: usize, rows: usize, bin: usize, page: usize, colors: &[&[usize]]) -> Writer {
701        let colors: Vec<Vec<(usize, f64)>> = colors
702            .iter()
703            .map(|color| color.iter().map(|&block| (block, 1.0)).collect())
704            .collect();
705        let borrowed: Vec<&[(usize, f64)]> = colors.iter().map(|c| c.as_slice()).collect();
706        weighed(width, rows, bin, page, &borrowed)
707    }

709    /// The same, with a weight on every term rather than the 1 an unweighted
710    /// colour carries.
711    fn weighed(
712        width: usize,
713        rows: usize,
714        bin: usize,
715        page: usize,
716        colors: &[&[(usize, f64)]],
717    ) -> Writer {
718        let mut w = Writer::new(UNWRITTEN, width, rows, bin, page).unwrap();
719        for color in colors {
720            for &(block, weight) in *color {
721                w.set(block, weight);
722            }
723            w.end_transaction().unwrap();
724        }
725        w
726    }

827    /// white, ink black, and the diagonal where the fold put it --- checked

838        let mut reader = decoder.read_info().unwrap();

842        assert_eq!(info.color_type, png::ColorType::Grayscale);
