1//! # What the driver needs a color to be
2//!
3//! [`crate::poly`] is a port of a Knuth exercise and the circular list is its
4//! whole subject, so it stays exactly as it is.  But the *driver* does not
5//! actually need polynomials.  It needs sets of block ids: every coefficient it
6//! ever handles is 1, and `ior` on 1s is 1, so a color is a set and `ior` is
7//! union — `main` says as much in its own docs.
8//!
9//! That gap is worth something.  A set of small integers can live in a flat
10//! sorted array, where a union is a sequential scan of two runs of `u32` rather
11//! than a chase down two chains of 24-byte nodes, and where a vector unit has
12//! something to work on.  A ring cannot be walked that way: the merge in
13//! [`crate::poly::Arena::op`] loads `next` to find out where to load next, so it
14//! is latency-bound, and no vector instruction shortens a dependent load.
15//!
16//! So there are two implementations, and this trait is the line between them:
17//!
18//! - [`RingStore`] — the exercise, wrapping [`crate::poly::Arena`] untouched.
19//! - [`crate::colorset::SetStore`] — sorted arrays, for speed.
20//!
21//! Keeping both is not sentiment.  The driver is deterministic and its output is
22//! byte for byte comparable, so running the same records through both backends
23//! and diffing is an equivalence check between two implementations that share no
24//! code — a stronger statement about the fast one than any test it could be
25//! given on its own.
26//!
27//! ## Why the trait is shaped this way
28//!
29//! [`ColorStore::union`] takes its operands **by reference** and neither is
30//! consumed, which is already [`crate::poly::Arena::op`]'s contract.  What the
31//! driver must be explicit about instead is wanting a *second handle* on a
32//! color, [`ColorStore::share`], because that is a ring copy for one backend and
33//! a refcount bump for the other — the whole difference between them, in one
34//! method.
35//!
36//! Nothing here is dyn-safe, on purpose: `run` is generic over this trait and
37//! instantiated once per backend, so the calls compile to what they would if the
38//! backend were named directly.
39
40use crate::poly::{Arena, Idx};
41
42/// A place colors live, and everything the driver does to them.
43///
44/// A [`ColorStore::Color`] is a handle whose meaning is private to the store
45/// that made it; handing one to a different store is a bug this trait cannot
46/// prevent.  Handles are owned — [`ColorStore::release`] each exactly once —
47/// which is why `Color` is deliberately not `Copy`.
48pub trait ColorStore {
49    type Color;
50
51    fn new() -> Self;
52
53    /// The color of a coinbase transaction: the one block that minted it.
54    fn singleton(&mut self, block: usize) -> Self::Color;
55
56    /// Set union.  Borrows both operands and leaves them untouched.
57    fn union(&mut self, a: &Self::Color, b: &Self::Color) -> Self::Color;
58
59    /// A second owned handle on the same color.  A copy for [`RingStore`], a
60    /// refcount bump for a sharing store; callers should assume it is expensive.
61    fn share(&mut self, color: &Self::Color) -> Self::Color;
62
63    /// Give a handle back.  It must not be used again.
64    fn release(&mut self, color: Self::Color);
65
66    /// Visit the blocks in decreasing order as `(exponent, coefficient)` pairs.
67    /// The coefficient is always 1; it survives because the output format is the
68    /// polynomial one and has to stay byte for byte what it was.
69    fn for_each_term(&self, color: &Self::Color, f: impl FnMut(usize, usize));
70
71    /// `(live, committed)` in whatever unit the store counts, for `--stats`,
72    /// with [`ColorStore::usage_labels`] naming them.  The backends count
73    /// different things, so these compare across a run, not across backends.
74    fn usage(&self) -> (usize, usize);
75
76    fn usage_labels(&self) -> (&'static str, &'static str);
77
78    /// One line saying whether everything the store thinks is live is reachable
79    /// from the colors the driver still holds.  A leak is invisible in the
80    /// output — a leaked color is still a *correct* color — so it needs its own
81    /// check.
82    fn audit(&self, live: &mut dyn Iterator<Item = &Self::Color>) -> String;
83}
84
85/// The circular-list backend: [`crate::poly::Arena`] plus the one thing the
86/// arena has no room for, a shared empty ring to copy against.
87///
88/// The empty ring is what the driver used to call `zero` and use as its fold
89/// seed.  The fold no longer needs a seed, but [`ColorStore::share`] does need
90/// something to merge against in order to produce a copy, and allocating a fresh
91/// empty ring per call would be silly.  It is one node, which is exactly what
92/// `zero` cost before, so `--stats` reads the same as it always did.
93pub struct RingStore {
94    arena: Arena,
95    empty: Idx,
96}
97
98impl ColorStore for RingStore {
99    type Color = Idx;
100
101    fn new() -> Self {
102        let mut arena = Arena::new();
103        let empty = arena.make(&[]);
104        RingStore { arena, empty }
105    }
106
107    fn singleton(&mut self, block: usize) -> Idx {
108        self.arena.make(&[(block, 1)])
109    }
110
111    fn union(&mut self, a: &Idx, b: &Idx) -> Idx {
112        self.arena.ior(*a, *b)
113    }
114
115    fn share(&mut self, color: &Idx) -> Idx {
116        // No refcount to bump, so a second handle is a second ring.  Union with
117        // the empty ring is the identity, so it is also a term-for-term copy.
118        self.arena.ior(*color, self.empty)
119    }
120
121    fn release(&mut self, color: Idx) {
122        self.arena.free_ring(color);
123    }
124
125    fn for_each_term(&self, color: &Idx, f: impl FnMut(usize, usize)) {
126        self.arena.for_each_term(*color, f);
127    }
128
129    fn usage(&self) -> (usize, usize) {
130        (self.arena.live(), self.arena.capacity())
131    }
132
133    fn usage_labels(&self) -> (&'static str, &'static str) {
134        ("live nodes", "arena nodes")
135    }
136
137    fn audit(&self, live: &mut dyn Iterator<Item = &Idx>) -> String {
138        let reachable: usize = self.arena.ring_len(self.empty)
139            + live.map(|&root| self.arena.ring_len(root)).sum::<usize>();
140        let held = self.arena.live();
141        if reachable == held {
142            format!("audit: {} live nodes, all reachable", held)
143        } else {
144            format!(
145                "audit: LEAK -- {} live nodes but only {} reachable ({} lost)",
146                held,
147                reachable,
148                held - reachable
149            )
150        }
151    }
152}
