1//! # Colors as weighted distributions over block ids
2//!
3//! The backend behind `--weighted`.  Where [`crate::colorset`] answers *which*
4//! blocks a transaction's coins came from, this answers *how much of it* came
5//! from each.
6//!
7//! ## What the weights mean
8//!
9//! A transaction spending inputs of amounts `a_1..a_n` from transactions with
10//! colors `C_1..C_n` is colored
11//!
12//! ```text
13//!     C  =  sum_i  (a_i / sum_j a_j) . C_i
14//! ```
15//!
16//! so each ancestor contributes in proportion to how much of this transaction's
17//! value flowed through it.  A coinbase is `{ block: 1 }` — all of it was minted
18//! in one place.
19//!
20//! Two things follow, and both are worth stating because they are what make the
21//! representation checkable:
22//!
23//! - **Every color sums to 1.**  The weights of a fold sum to 1 by construction
24//!   and each `C_i` sums to 1 by induction, so the result does too.  This is an
25//!   invariant, not an aspiration: `--stats` reports the worst drift it saw.
26//! - **The support is unchanged.**  Which blocks appear is exactly what the
27//!   unweighted backend computes; only the coefficients differ.  So colors grow
28//!   no faster here than there, and nothing is pruned — same as
29//!   [`crate::poly`], which never drops a cancelled term either.
30//!
31//! ## Layout: two arrays, not one array of pairs
32//!
33//! A color is a sorted `u32` of block ids beside an `f64` of weights, at the
34//! same indices.  Interleaving them into one array of `(u32, f64)` would be one
35//! allocation instead of three, but it would pad each pair to 16 bytes and, more
36//! to the point, put a block id between every two weights.  The arithmetic here
37//! runs over weights alone; keeping them contiguous is what lets
38//! [`crate::simd::scale_into`] and [`crate::simd::scale_add_into`] work a vector
39//! at a time.
40//!
41//! ## Where the vector work actually is
42//!
43//! Not in the merge.  Deciding which of two sorted key arrays advances is a
44//! data-dependent branch per element, and a measured attempt at a vector merge
45//! for the unweighted backend came out *slower* than the branchless scalar one.
46//! What weighting adds is arithmetic, and the arithmetic is elementwise:
47//!
48//! - a run of blocks only one side has is that side's weights times a scalar;
49//! - a run both sides have is `wa * A + wb * B`.
50//!
51//! Both are flat loops over contiguous `f64`, which vectorise.  The merge finds
52//! the runs; the vector unit does them.
53//!
54//! That the runs are long is not an assumption: counted over records 1.4-1.5 M
55//! of the 2022 chain, 97% of the terms a merge writes arrive in runs, the
56//! one-sided ones averaging 1,900 blocks and the shared ones 140.  Colours at
57//! that depth are near-copies of a few common ancestors, not independent
58//! mixtures.  A block-at-a-time gear for the short runs was built and measured
59//! -- 12 to 9 ns a term on synthetic colours that *were* independent mixtures,
60//! and nothing on the real chain, where it could reach 3% of the terms -- and
61//! dropped.
62//!
63//! ## Where the memory goes, and how it is allocated
64//!
65//! A colour is two boxed slices, allocated exactly once at their final length
66//! -- or at an upper bound and shrunk in place, for a merge, whose length is
67//! not known until it has run.  Nothing is staged and copied.  That relies on
68//! the allocator shrinking without moving and without waste, which jemalloc
69//! does and glibc's malloc and mimalloc were measured not to (see the features
70//! in `Cargo.toml`): on the same 1.5 M records the resident set was 32.0 GB
71//! under jemalloc, 37.4 GB under glibc and 39.8 GB under mimalloc.  The store
72//! is what runs into this machine's memory, so the allocator is not a detail.
73

80/// Blocks ascending, weights alongside.  Always the same length.
81pub struct Terms {
82    blocks: Box<[u32]>,
83    weights: Box<[f64]>,
84}
85
86impl Terms {
87    fn len(&self) -> usize {
88        self.blocks.len()
89    }
90}
91
92pub type Color = Rc<Terms>;

94pub struct WeightedSets {
95    live: usize,
96    peak: usize,
97    /// The largest `|sum of weights - 1|` seen in a finished color.  Every color
98    /// is a distribution, so this is the accumulated floating-point drift and
99    /// nothing else; if it ever stops being tiny, the arithmetic is wrong.
100    drift: f64,
101}
102
103impl WeightedSets {
104    /// Freeze a finished pair of arrays into a colour.
105    ///
106    /// The vectors arrive with their length set to what was written and their
107    /// capacity at whatever upper bound the caller had, and `into_boxed_slice`
108    /// gives the difference back — a `realloc` downward, which jemalloc does in
109    /// place and to size (glibc and mimalloc do not; see the module docs).
110    /// Nothing is copied here, and that is the point: the merge used to build
111    /// into a staging buffer that was zeroed first and copied out after, and at
112    /// depth in the 2022 chain the zeroing, the copy and the `malloc` behind it
113    /// were half the fold.
114    fn intern(&mut self, blocks: Vec<u32>, weights: Vec<f64>) -> Color {
115        debug_assert_eq!(blocks.len(), weights.len());
116        let color = Rc::new(Terms {
117            blocks: blocks.into_boxed_slice(),
118            weights: weights.into_boxed_slice(),
119        });
120        self.live += color.len();
121        self.peak = self.peak.max(self.live);
122        color
123    }
124}
125
126/// `dst[..src.len()] = src`, into memory that has not been initialised.
127///
128/// What `copy_from_slice` is for the block ids once the destination is a fresh
129/// allocation rather than a zeroed buffer.  The standard library has this as
130/// `MaybeUninit::copy_from_slice`, but not on stable yet.
131#[inline]
132fn put(dst: &mut [MaybeUninit<u32>], src: &[u32]) {
133    assert!(dst.len() >= src.len(), "run of {} into room for {}", src.len(), dst.len());
134    // SAFETY: `src` is a live slice of `src.len()` initialised `u32`s, `dst` has
135    // room for at least that many, and the two cannot overlap -- one borrows a
136    // finished colour, the other the allocation being built.
137    unsafe {
138        std::ptr::copy_nonoverlapping(src.as_ptr(), dst.as_mut_ptr() as *mut u32, src.len());
139    }
140}
141
142/// `wa * a + wb * b` into fresh, uninitialised output slices, answering how
143/// many terms it wrote.  Every element below that count is initialised on
144/// return; nothing above it is touched.
145///
146/// One pass over both inputs.  A run that only one side has is copied and scaled
147/// through [`simd::scale_into_uninit`]; a run they share goes through
148/// [`simd::scale_add_into_uninit`].  Finding those runs is the scalar part, and
149/// it is the part that resists vectorising — which is why the loop below looks
150/// for *runs* rather than stepping one block at a time: the longer the runs, the
151/// more of the work lands in the vector helpers.
152///
153/// Two things about how the runs are found, both measured on the real chain
154/// where colours reach a hundred thousand blocks:
155///
156/// - the one-sided run is found by galloping ([`simd::leading_below`]) rather
157///   than bisecting the whole remainder, because bisection's probes land far
158///   ahead of where the merge is streaming and miss the cache, and most runs are
159///   short next to the colour;
160/// - the shared run is found four blocks at a time ([`simd::common_prefix`]),
161///   since a scalar walk of it was one dependent compare per block over stretches
162///   that are exactly as long as the colours are shared, which is most of them.
163fn combine_into(
164    out_blocks: &mut [MaybeUninit<u32>],
165    out_weights: &mut [MaybeUninit<f64>],
166    a: &Terms,
167    wa: f64,
168    b: &Terms,
169    wb: f64,
170) -> usize {
171    let (mut i, mut j, mut k) = (0usize, 0usize, 0usize);
172
173    while i < a.len() && j < b.len() {
174        let (ka, kb) = (a.blocks[i], b.blocks[j]);
175
176        if ka < kb {
177            // A run of A that B does not reach yet: scale and copy it whole.
178            let run = simd::leading_below(&a.blocks[i..], kb);
179            put(&mut out_blocks[k..k + run], &a.blocks[i..i + run]);
180            simd::scale_into_uninit(
181                &mut out_weights[k..k + run],
182                &a.weights[i..i + run],
183                wa,
184            );
185            i += run;
186            k += run;
187        } else if kb < ka {
188            let run = simd::leading_below(&b.blocks[j..], ka);
189            put(&mut out_blocks[k..k + run], &b.blocks[j..j + run]);
190            simd::scale_into_uninit(
191                &mut out_weights[k..k + run],
192                &b.weights[j..j + run],
193                wb,
194            );
195            j += run;
196            k += run;
197        } else {
198            // A run both sides carry, block for block.  Common: colors that
199            // share an ancestor share whole stretches of its support.
200            let run = simd::common_prefix(&a.blocks[i..], &b.blocks[j..]);
201            put(&mut out_blocks[k..k + run], &a.blocks[i..i + run]);
202            simd::scale_add_into_uninit(
203                &mut out_weights[k..k + run],
204                &a.weights[i..i + run],
205                wa,
206                &b.weights[j..j + run],
207                wb,
208            );
209            i += run;
210            j += run;
211            k += run;
212        }
213    }
214
215    // Whatever is left of one side is a single scaled run.
216    let rest_a = a.len() - i;
217    put(&mut out_blocks[k..k + rest_a], &a.blocks[i..]);
218    simd::scale_into_uninit(&mut out_weights[k..k + rest_a], &a.weights[i..], wa);
219    k += rest_a;
220
221    let rest_b = b.len() - j;
222    put(&mut out_blocks[k..k + rest_b], &b.blocks[j..]);
223    simd::scale_into_uninit(&mut out_weights[k..k + rest_b], &b.weights[j..], wb);
224    k + rest_b
225}

227impl ColorStore for WeightedSets {
228    type Color = Color;
229
230    const WEIGHTED: bool = true;
231
232    fn new() -> Self {
233        WeightedSets {
234            live: 0,
235            peak: 0,
236            drift: 0.0,
237        }
238    }
239
240    fn singleton(&mut self, block: usize) -> Color {
241        let block = u32::try_from(block)
242            .unwrap_or_else(|_| panic!("block id {} does not fit in a u32 — see weighted", block));
243        self.intern(vec![block], vec![1.0])
244    }
245
246    fn combine(&mut self, a: &Color, wa: f64, b: &Color, wb: f64) -> Color {
247        if a.len() == 0 {
248            return self.scale(b, wb);
249        }
250        if b.len() == 0 {
251            return self.scale(a, wa);
252        }
253
254        // Unlike the unweighted store there is no shortcut for `a` and `b` being
255        // the same allocation: `wa * C + wb * C` is `(wa + wb) * C`, which is
256        // still a scale rather than nothing.
257        if Rc::ptr_eq(a, b) {
258            return self.scale(a, wa + wb);
259        }
260
261        // The result has at most as many terms as the two sides together, and
262        // exactly how many is not known until the merge has run.  So: allocate
263        // the bound, merge straight into it, and let `intern` hand the unused
264        // tail back.
265        let bound = a.len() + b.len();
266        let mut blocks: Vec<u32> = Vec::with_capacity(bound);
267        let mut weights: Vec<f64> = Vec::with_capacity(bound);
268        let written = combine_into(
269            blocks.spare_capacity_mut(),
270            weights.spare_capacity_mut(),
271            a,
272            wa,
273            b,
274            wb,
275        );
276        // SAFETY: `combine_into` initialised exactly the first `written`
277        // elements of both, and `written <= bound`.
278        unsafe {
279            blocks.set_len(written);
280            weights.set_len(written);
281        }
282        self.intern(blocks, weights)
283    }
284
285    fn scale(&mut self, color: &Color, w: f64) -> Color {
286        // Weight 1 changes nothing, and a transaction with a single input is
287        // exactly that case -- its one ancestor contributes all of the value.
288        // Sharing rather than rebuilding keeps the commonest shape free.
289        if w == 1.0 {
290            return self.share(color);
291        }
292        // The length is known here, so both arrays are allocated exactly: the
293        // blocks are a straight copy and the weights are scaled into place.
294        let n = color.len();
295        let blocks = color.blocks.to_vec();
296        let mut weights: Vec<f64> = Vec::with_capacity(n);
297        simd::scale_into_uninit(weights.spare_capacity_mut(), &color.weights, w);
298        // SAFETY: `scale_into_uninit` wrote all `n` elements.
299        unsafe { weights.set_len(n) };
300        self.intern(blocks, weights)
301    }
302
303    fn share(&mut self, color: &Color) -> Color {
304        Rc::clone(color)
305    }
306
307    /// Every finished color is a distribution, so its weights sum to 1 and
308    /// anything else is accumulated floating-point drift.  Tracking the worst of
309    /// it turns the invariant into something a run can actually report.
310    fn observe(&mut self, color: &Color) {
311        let total: f64 = color.weights.iter().sum();
312        self.drift = self.drift.max((total - 1.0).abs());
313    }
314
315    fn release(&mut self, color: Color) {
316        if Rc::strong_count(&color) == 1 {
317            self.live -= color.len();
318        }
319    }
320
321    fn for_each_term(&self, color: &Color, mut f: impl FnMut(usize, f64)) {
322        // Stored ascending because that is what a merge wants; printed in
323        // decreasing exponent order, like the polynomial it stands in for.
324        for k in (0..color.len()).rev() {
325            f(color.blocks[k] as usize, color.weights[k]);
326        }
327    }
328
329    fn usage(&self) -> (usize, usize) {
330        (self.live, self.peak)
331    }
332
333    fn usage_labels(&self) -> (&'static str, &'static str) {
334        ("live terms", "peak terms")
335    }
336
337    fn audit(&self, live: &mut dyn Iterator<Item = &Color>) -> String {
338        let mut seen: HashSet<*const Terms> = HashSet::new();
339        let mut reachable = 0;
340        for color in live {
341            if seen.insert(Rc::as_ptr(color)) {
342                reachable += color.len();
343            }
344        }
345        let leak = if reachable == self.live {
346            format!("{} live terms, all reachable", self.live)
347        } else {
348            format!(
349                "LEAK -- {} live terms but only {} reachable",
350                self.live, reachable
351            )
352        };
353        format!("audit: {}, worst drift from sum 1 was {:.3e}", leak, self.drift)
354    }
355}

361    fn color(store: &mut WeightedSets, terms: &[(u32, f64)]) -> Color {
362        let (blocks, weights): (Vec<u32>, Vec<f64>) = terms.iter().copied().unzip();
363        store.intern(blocks, weights)
364    }

366    fn dump(c: &Color) -> Vec<(u32, f64)> {
367        c.blocks
368            .iter()
369            .copied()
370            .zip(c.weights.iter().copied())
371            .collect()
372    }

374    /// What a weighted union is, written out slowly: gather every block from
375    /// both sides, scale, and add where they meet.
376    fn oracle(a: &[(u32, f64)], wa: f64, b: &[(u32, f64)], wb: f64) -> Vec<(u32, f64)> {
377        let mut all: std::collections::BTreeMap<u32, f64> = std::collections::BTreeMap::new();
378        for &(block, weight) in a {
379            *all.entry(block).or_insert(0.0) += weight * wa;
380        }
381        for &(block, weight) in b {
382            *all.entry(block).or_insert(0.0) += weight * wb;
383        }
384        all.into_iter().collect()
385    }
386
387    fn check(a: &[(u32, f64)], wa: f64, b: &[(u32, f64)], wb: f64) {
388        let mut store = WeightedSets::new();
389        let ca = color(&mut store, a);
390        let cb = color(&mut store, b);
391        let combined = store.combine(&ca, wa, &cb, wb);
392        let got = dump(&combined);
393        let want = oracle(a, wa, b, wb);
394        assert_eq!(got.len(), want.len(), "a={:?} b={:?}", a, b);
395        for (g, w) in got.iter().zip(&want) {
396            assert_eq!(g.0, w.0, "blocks differ: {:?} vs {:?}", got, want);
397            assert!(
398                (g.1 - w.1).abs() < 1e-12,
399                "weight for block {} is {} not {}",
400                g.0,
401                g.1,
402                w.1
403            );
404        }
405    }

556            ("two mixed colours, 77% of 40k blocks each (L2)", dense(40_000, 0.77), dense(40_000, 0.77)),
557            ("two well-mixed colours, 92% of 130k blocks each (runs ~5)", dense(130_000, 0.92), dense(130_000, 0.92)),
558            ("mixed 77% of 130k against a half-dense 50% one", dense(130_000, 0.77), dense(130_000, 0.5)),
559            ("mixed 77% of 130k against a sparse 4% one", dense(130_000, 0.77), dense(130_000, 0.04)),
560            ("nearly identical 100k-block colours (long shared runs)", dense(130_000, 0.77), Vec::new()),
561            ("disjoint interleaved 50k each (runs of one)", (0..100_000).filter(|b| b % 2 == 0).map(|b| (b, 2e-5)).collect(), (0..100_000).filter(|b| b % 2 == 1).map(|b| (b, 2e-5)).collect()),
562        ];
563        for (name, a, b) in shapes {
564            let b = if b.is_empty() {
565                // Nearly identical: drop every 500th block of `a`.
566                a.iter().enumerate().filter(|(k, _)| k % 500 != 0).map(|(_, t)| *t).collect()
567            } else {
568                b
569            };
570            let mut store = WeightedSets::new();
571            let ca = color(&mut store, &a);
572            let cb = color(&mut store, &b);
573            let mut best = f64::INFINITY;
574            let mut out_len = 0;
575            for _ in 0..7 {
576                let started = Instant::now();
577                let reps = 20;
578                for _ in 0..reps {
579                    let c = store.combine(&ca, 0.6, &cb, 0.4);
580                    out_len = c.len();
581                    store.release(c);
582                }
583                let per_term = started.elapsed().as_secs_f64() * 1e9 / (reps * out_len) as f64;
584                best = best.min(per_term);
585            }
586            eprintln!(
587                "merge_bench: {:<58} a={:>7} b={:>7} out={:>7}  {:.3} ns/term",
588                name, a.len(), b.len(), out_len, best
589            );
590        }
591    }
