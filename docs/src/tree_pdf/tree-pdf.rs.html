1//! # A subtree, written as a page
2//!
3//! The drawing `tree-view` shows and `tree-jp2` rasters, cut down to the
4//! subtree of a node one names, and written as a vector PDF a paper can take:
5//!
6//! ```text
7//! tree-pdf <graph-basename> --root <id>[,<id>...] -o <file>
8//!          [--depth <n>] [--max-nodes <n>] [--fanout <n>]
9//!          [--vertical] [--fill] [--width <pt>] [--max-height <pt>]
10//!          [--mark <id>[,<id>...]] [--labels] [--spine <id>[,<id>...]]
11//!          [--ghost]
12//!          [--ancestors <transpose-basename> [--depth-up <n>] [--fanout-up <n>] [--max-nodes-up <n>]]
13//! ```
14//!
15//! The graph this exists for has two billion nodes, and no page holds two
16//! billion of anything.  What a page *can* hold is a neighbourhood: the walk
17//! starts at the named roots instead of sweeping the whole graph, and the
18//! three scissors of [`forest::Prune`] — `--depth`, `--max-nodes`, `--fanout`
19//! — say where it stops.  Run on the transpose graph the same command draws a
20//! node's *ancestors*: the transpose's successors are the graph's
21//! predecessors, so `--root` there reads as "where did this come from" rather
22//! than "where did this go".
23//!
24//! # The ink
25//!
26//! The layout and the shapes are the viewers': depth runs left to right, a
27//! node is a circle, a node with children is filled and a leaf is hollow once
28//! there is room for a ring, and the arcs to parents are drawn behind them in
29//! a grey that stays behind.  One tone is this binary's own — a node whose
30//! successors the cut left out is filled in a warning colour, because a
31//! pruned frontier drawn like a fringe of true leaves would be the drawing
32//! lying about the graph.  The count of such nodes is on stderr too, and a
33//! caption quoting it is telling the truth about the picture.
34//!
35//! # What a tree cannot draw
36//!
37//! A spanning tree keeps one arc per node — the first one to reach it — and
38//! that is not a small loss on this graph.  Its arcs are the disjoint union
39//! of complete bipartite blocks `K(I, O)`, one per transaction, so when the
40//! walk expands the first input of a block it meets, the whole of `O` hangs
41//! under that one input and each later input finds its `|O|` successors drawn
42//! already and keeps none: every block is flattened to a star `K(1, |O|)`
43//! with `|I| - 1` childless nodes beside it.  Three arcs in four go this way.
44//! A figure drawn under that rule is a true picture of the *tree* and a
45//! misleading picture of the *graph*, which is why the count of dropped arcs
46//! has always been on stderr for a caption to quote.
47//!
48//! `--ghost` puts them back.  The walk keeps the endpoints of the arcs it
49//! drops, and they are stroked behind the tree in a dashed, paler ink: the
50//! same page then carries both readings, the tree in its own grey and, under
51//! it, the biclique the tree turned into a star.  The tree arcs go from a
52//! node to its one parent; the ghosts go from a node to every *other* parent
53//! it has, which is a picture of exactly the structure the numbering imposes.
54//! Only the pairs are capped ([`forest::GHOST_LIMIT`]) — the count never is —
55//! and a run whose ledger the cap cut short refuses to draw rather than
56//! quietly omit arcs the caption would claim.
57//!
58//! # The page
59//!
60//! Written by [`pdf`], which is this crate and `flate2` and nothing else — no
61//! Cairo, no toolkit, nothing to install.  Cairo's pages and these agree
62//! about what a drawing is; this one exists so that a machine with a graph
63//! and a Rust toolchain can make a figure.
64//!
65//! The page is sized to the drawing rather than the drawing to a page: the
66//! scale is whatever fits `--width` points across (and `--max-height` down,
67//! whichever binds), and the page then hugs the drawing.  A node never
68//! shrinks below a third of a point — on a page of thousands of levels the
69//! circles are the drawing's *texture*, and a reader zooming into the PDF
70//! still finds every one of them a circle, because a page description has no
71//! resolution to run out of.

97const USAGE: &str = "usage: tree-pdf <graph-basename> --root <id>[,<id>...] -o <file>\n\
98       [--depth <n>] [--max-nodes <n>] [--fanout <n>]\n\
99       [--vertical] [--fill] [--width <pt>] [--max-height <pt>]\n\
100       [--mark <id>[,<id>...]] [--labels] [--spine <id>[,<id>...]]\n\
101       [--ghost]\n\
102       [--ancestors <transpose-basename> [--depth-up <n>] [--fanout-up <n>] [--max-nodes-up <n>]]";

104/// One tree of a drawing: the descendants of the root, or --- `flipped`, on
105/// the other side of it --- its ancestors.
106///
107/// A plain subtree page is one part.  An *hourglass* (`--ancestors`) is two:
108/// the same root walked forward on the graph and backward on its transpose,
109/// composed about the one node they share, so that a single page answers both
110/// of the forensic questions --- where did this come from, and where did it
111/// go.  The flipped part's depth axis runs in the negative direction, which on
112/// a vertical page puts the past above the event and the future below it.
113struct Part<'a> {
114    scene: &'a Scene,
115    truncated: &'a HashSet<usize>,
116    /// The arcs this part's walk dropped, `(tail, head)` as graph ids, for
117    /// `--ghost` to stroke behind the tree; empty when the caller did not ask
118    /// for them.  Both ends are drawn nodes of *this* part, so the drawing
119    /// resolves them against this part's own scene and no other.
120    dropped: &'a [(u32, u32)],
121    flipped: bool,
122}
123
124/// How the page is settled: everything about the drawing that is not a tree.
125struct Layout {
126    width: f64,
127    max_height: f64,
128    fill: bool,
129    vertical: bool,
130    labels: bool,
131    /// Whether each part's dropped arcs are stroked behind its tree.  See the
132    /// module's "What a tree cannot draw".
133    ghost: bool,
134}
135
136/// Draws laid-out scenes as one page: each part's `truncated` being the graph
137/// ids whose successors its cut left out, and `marks` the ids the caller asked
138/// to have inked apart.
139///
140/// Two ways of settling the scale.  By default one scale serves both axes ---
141/// whichever of `width` and `max_height` binds --- and the page then hugs the
142/// drawing, so its shape is the drawing's shape.  With `fill` the two axes are
143/// scaled *independently* to the page the caller asked for, exactly as
144/// `tree-jp2` spends different pixels per unit on depth and breadth: the trees
145/// of this graph are routinely a hundred times broader than they are deep, and
146/// a uniform scale would render such a subtree as a ribbon eleven points tall
147/// on a page meant to hold a plate.  Stretching the depth axis spreads the
148/// generations down the page without moving any node relative to another in
149/// its level; what it costs is that distances no longer mean the same thing on
150/// the two axes, which is why it is the caller's flag and not the default.
151///
152/// `vertical` must say which axis is depth, because the node radius keys on
153/// the tighter of the two spacings --- a level is 1 unit along depth, sibling
154/// centres 2 units along breadth --- and under `fill` the axes no longer agree.
155fn draw(parts: &[Part], marks: &HashSet<usize>, opts: &Layout) -> Page {
156    // Every part is expressed in coordinates centred on its root --- scene
157    // index 0, since a single named root is walked first --- with the depth
158    // axis negated for a flipped part, so an hourglass's two trees meet at
159    // one shared point.
160    let centred = |part: &Part<'_>, i: u32| {
161        let [rx, ry] = part.scene.at(0);
162        let [x, y] = part.scene.at(i);
163        let (mut dx, mut dy) = (x - rx, y - ry);
164        if part.flipped {
165            if opts.vertical {
166                dy = -dy;
167            } else {
168                dx = -dx;
169            }
170        }
171        (dx, dy)
172    };
173
174    let mut bounds = camera::Rect::nothing();
175    for part in parts {
176        for i in 0..part.scene.len() as u32 {
177            let (x, y) = centred(part, i);
178            bounds.add(x, y);
179        }
180    }
181    let bounds = bounds.grown(parts[0].scene.radius());
182
183    // Labels overhang the circles they name, so a labelled page keeps more
184    // clear paper around the drawing than a plain one.
185    let margin = if opts.labels { MARGIN + 12.0 } else { MARGIN };
186
187    let (scale_x, scale_y, page_w, page_h) = if opts.fill {
188        (
189            (opts.width - 2.0 * margin) / bounds.width(),
190            (opts.max_height - 2.0 * margin) / bounds.height(),
191            opts.width,
192            opts.max_height,
193        )
194    } else {
195        let scale = ((opts.width - 2.0 * margin) / bounds.width())
196            .min((opts.max_height - 2.0 * margin) / bounds.height());
197        (
198            scale,
199            scale,
200            bounds.width() * scale + 2.0 * margin,
201            bounds.height() * scale + 2.0 * margin,
202        )
203    };
204
205    // PDF's y runs up the page and the layout's runs down the drawing, so the
206    // flip lives here, in the one mapping every mark goes through.
207    let at = |part: &Part<'_>, i: u32| {
208        let (x, y) = centred(part, i);
209        (
210            margin + (x - bounds.min_x) * scale_x,
211            page_h - margin - (y - bounds.min_y) * scale_y,
212        )
213    };
214
215    // The ink is a shade smaller than the tightest spacing on the page, so
216    // that the beads of a chain part instead of fusing into a bar; the floor
217    // keeps a node printable however far out the scale is.  Levels sit 1 unit
218    // apart along the depth axis and sibling centres 2 apart along breadth,
219    // which under `fill` are different numbers of points.
220    let (depth_scale, breadth_scale) = if opts.vertical {
221        (scale_y, scale_x)
222    } else {
223        (scale_x, scale_y)
224    };
225    let spacing = depth_scale.min(2.0 * breadth_scale);
226    let radius = (0.5 * spacing * INK).clamp(MIN_RADIUS, MAX_RADIUS);
227    let hollow = radius >= MIN_HOLLOW;
228
229    // The root belongs to every part but is drawn once, by the first: what a
230    // later part contributes at index 0 is its edges, not a second disc.
231    let drawn = |p: usize, i: u32| p == 0 || i != 0;
232
233    let mut page = Page::new(page_w, page_h);
234
235    // The ghosts first of all, under even the tree's own arcs: what the walk
236    // dropped is the *background* against which what it kept is read, and an
237    // arc drawn over a ghost says which of the two the tree chose.  A part's
238    // pairs are graph ids, so each part carries its own id-to-index map;
239    // built here rather than in the scene because only this flag wants it.
240    if opts.ghost && parts.iter().any(|part| !part.dropped.is_empty()) {
241        page.set_stroke(GHOST);
242        page.set_line_width((radius / 3.5).clamp(0.14, 0.9));
243        page.set_dash(GHOST_DASH.0, GHOST_DASH.1);
244        let mut in_path = 0;
245        for part in parts {
246            if part.dropped.is_empty() {
247                continue;
248            }
249            let mut index: HashMap<u32, u32> =
250                HashMap::with_capacity(part.scene.len());
251            for i in 0..part.scene.len() as u32 {
252                index.insert(part.scene.node(i).graph, i);
253            }
254            for &(tail, head) in part.dropped {
255                // A pair whose ends are not both on the page is not drawn and
256                // not silently forgotten either: `run` compares the count it
257                // drew with the count the walk reported.
258                let (Some(&t), Some(&h)) = (index.get(&tail), index.get(&head)) else {
259                    continue;
260                };
261                let (tx, ty) = at(part, t);
262                let (hx, hy) = at(part, h);
263                page.segment(tx, ty, hx, hy);
264                in_path += 1;
265                if in_path == BATCH {
266                    page.stroke();
267                    in_path = 0;
268                }
269            }
270        }
271        if in_path > 0 {
272            page.stroke();
273        }
274        page.solid();
275    }
276
277    // The tree's own arcs next, behind the nodes: one grey, one width, one
278    // stroke per batch.
279    page.set_stroke(LINK);
280    page.set_line_width((radius / 3.0).clamp(0.16, 1.2));
281    let mut in_path = 0;
282    for part in parts {
283        for i in 0..part.scene.len() as u32 {
284            let parent = part.scene.node(i).parent;
285            if parent == NO_PARENT {
286                continue;
287            }
288            let (px, py) = at(part, parent);
289            let (x, y) = at(part, i);
290            page.segment(px, py, x, y);
291            in_path += 1;
292            if in_path == BATCH {
293                page.stroke();
294                in_path = 0;
295            }
296        }
297    }
298    if in_path > 0 {
299        page.stroke();
300    }
301
302    // The nodes, sorted into the few kinds they are drawn as, each colour
303    // named once.  Filled says something hangs under the node *in this
304    // drawing*, hollow says nothing does, exactly as in the viewers; the
305    // warning colour says the cut took some of the node's successors, whether
306    // or not it left it any --- so a filled warning node is an incomplete fan,
307    // and a hollow one is a frontier the drawing stops at --- and a marked
308    // node wears the caller's colour over whatever else it is: the subject of
309    // the drawing outranks the bookkeeping of its cut.
310    let class = |part: &Part<'_>, i: u32| {
311        let graph = part.scene.node(i).graph as usize;
312        let leaf = usize::from(part.scene.is_leaf(i));
313        if marks.contains(&graph) {
314            4 + leaf
315        } else if part.truncated.contains(&graph) {
316            2 + leaf
317        } else {
318            leaf
319        }
320    };
321
322    for wanted in 0..=5 {
323        if !parts.iter().enumerate().any(|(p, part)| {
324            (0..part.scene.len() as u32).any(|i| drawn(p, i) && class(part, i) == wanted)
325        }) {
326            // A colour is named only over the nodes drawn in it: a page with
327            // nothing cut and nothing marked has neither ink in its bytes.
328            continue;
329        }
330        let colour = [INNER, LEAF, CUT, CUT, MARK, MARK][wanted];
331        // The odd classes are the childless ones, drawn hollow when there is
332        // room for a ring.
333        let rings = hollow && wanted % 2 == 1;
334        if rings {
335            // A ring is paper filled and the colour stroked, in one operator.
336            page.set_fill(PAPER);
337            page.set_stroke(colour);
338            page.set_line_width((radius / 3.0).clamp(0.3, 1.6));
339        } else {
340            page.set_fill(colour);
341        }
342        let mut in_path = 0;
343        for (p, part) in parts.iter().enumerate() {
344            for i in 0..part.scene.len() as u32 {
345                if !drawn(p, i) || class(part, i) != wanted {
346                    continue;
347                }
348                let (x, y) = at(part, i);
349                page.circle(x, y, radius);
350                in_path += 1;
351                if in_path == BATCH {
352                    if rings {
353                        page.fill_and_stroke();
354                    } else {
355                        page.fill();
356                    }
357                    in_path = 0;
358                }
359            }
360        }
361        if in_path > 0 {
362            if rings {
363                page.fill_and_stroke();
364            } else {
365                page.fill();
366            }
367        }
368    }
369
370    // The labels last, over everything: each node's graph id centred above
371    // its circle, where a chain has paper --- at its side it would lie across
372    // the next bead.  Asked for by flag because labels only earn their ink on
373    // a drawing of tens of nodes; the size follows the circles and never
374    // drops below legibility.
375    if opts.labels {
376        let size = (radius * 2.2).clamp(3.5, 7.0);
377        // Helvetica's digits are 0.556 em wide, which is all a graph id is
378        // made of: enough metrics to centre a label without carrying a font.
379        let digit = 0.556 * size;
380        page.set_fill(LABEL);
381        for (p, part) in parts.iter().enumerate() {
382            for i in 0..part.scene.len() as u32 {
383                if !drawn(p, i) {
384                    continue;
385                }
386                let (x, y) = at(part, i);
387                let label = part.scene.node(i).graph.to_string();
388                let width = digit * label.len() as f64;
389                // Alternating shoulders: siblings sit two units apart and an
390                // id is wider than that, so neighbours take turns above and
391                // below and each label gets its neighbour's clearance too.
392                let ly = if i % 2 == 0 {
393                    y + radius + 1.0
394                } else {
395                    y - radius - 1.0 - 0.72 * size
396                };
397                page.text(x - width / 2.0, ly, size, &label);
398            }
399        }
400    }
401
402    page
403}

405fn run() -> Result<(), String> {
406    let argv: Vec<String> = env::args().skip(1).collect();
407
408    let mut basenames: Vec<&str> = Vec::new();
409    let mut out_path: Option<&str> = None;
410    let mut roots: Vec<usize> = Vec::new();
411    let mut prune = forest::Prune { max_nodes: DEFAULT_MAX_NODES, ..forest::Prune::default() };
412    let mut width = DEFAULT_WIDTH;
413    let mut max_height = DEFAULT_MAX_HEIGHT;
414    let mut vertical = false;
415    let mut fill = false;
416    let mut labels = false;
417    let mut ghost = false;
418    let mut marks: HashSet<usize> = HashSet::new();
419    let mut ancestors: Option<&str> = None;
420    let mut depth_up: Option<usize> = None;
421    let mut fanout_up: Option<usize> = None;
422    let mut max_nodes_up: Option<usize> = None;
423
424    let mut i = 0;
425    while i < argv.len() {
426        match argv[i].as_str() {
427            "-o" | "--out" => {
428                i += 1;
429                out_path = Some(argv.get(i).ok_or_else(|| format!("-o wants a file\n{USAGE}"))?);
430            }
431            "--root" => {
432                i += 1;
433                let v = argv.get(i).ok_or_else(|| format!("--root wants a node id\n{USAGE}"))?;
434                for part in v.split(',') {
435                    let id = part
436                        .parse::<usize>()
437                        .map_err(|_| format!("--root {part}: not a node id"))?;
438                    roots.push(id);
439                }
440            }
441            "--depth" => {
442                i += 1;
443                let v = argv.get(i).ok_or_else(|| format!("--depth wants a number\n{USAGE}"))?;
444                prune.depth =
445                    Some(v.parse::<usize>().map_err(|_| format!("--depth {v}: not a number"))?);
446            }
447            "--max-nodes" => {
448                i += 1;
449                let v =
450                    argv.get(i).ok_or_else(|| format!("--max-nodes wants a number\n{USAGE}"))?;
451                prune.max_nodes = v
452                    .parse::<usize>()
453                    .ok()
454                    .filter(|&n| n > 0)
455                    .ok_or_else(|| format!("--max-nodes {v}: wants a positive number"))?;
456            }
457            "--fanout" => {
458                i += 1;
459                let v = argv.get(i).ok_or_else(|| format!("--fanout wants a number\n{USAGE}"))?;
460                prune.fanout = Some(
461                    v.parse::<usize>()
462                        .ok()
463                        .filter(|&n| n > 0)
464                        .ok_or_else(|| format!("--fanout {v}: wants a positive number"))?,
465                );
466            }
467            flag @ ("--width" | "--max-height") => {
468                i += 1;
469                let v = argv.get(i).ok_or_else(|| format!("{flag} wants a number\n{USAGE}"))?;
470                let pt = v
471                    .parse::<f64>()
472                    .ok()
473                    .filter(|&pt| pt > 2.0 * MARGIN)
474                    .ok_or_else(|| format!("{flag} {v}: a page needs a positive size"))?;
475                if flag == "--width" {
476                    width = pt;
477                } else {
478                    max_height = pt;
479                }
480            }
481            // Depth down the page instead of across it: what a fan wants --
482            // one level deep and a thousand siblings broad -- and what a chain
483            // does not.
484            "--vertical" => vertical = true,
485            // Scale the two axes independently so the drawing fills the page
486            // asked for, instead of one scale and a page that hugs the
487            // drawing.  See [`draw`] for what that buys and what it costs.
488            "--fill" => fill = true,
489            // Each node's graph id at its shoulder; for drawings small enough
490            // that a reader can be told which node is which.
491            "--labels" => labels = true,
492            // The arcs the walk dropped, stroked behind the tree it kept: a
493            // page that shows the biclique as well as the star it became.
494            // See the module's "What a tree cannot draw".
495            "--ghost" => ghost = true,
496            "--mark" => {
497                i += 1;
498                let v = argv.get(i).ok_or_else(|| format!("--mark wants a node id\n{USAGE}"))?;
499                for part in v.split(',') {
500                    marks.insert(
501                        part.parse::<usize>()
502                            .map_err(|_| format!("--mark {part}: not a node id"))?,
503                    );
504                }
505            }
506            // Only these nodes (and the roots) are expanded: the drawing is
507            // the named chain with every leg one node deep.  See
508            // [`forest::Prune::expand`].
509            "--spine" => {
510                i += 1;
511                let v = argv.get(i).ok_or_else(|| format!("--spine wants node ids\n{USAGE}"))?;
512                let spine = prune.expand.get_or_insert_with(HashSet::new);
513                for part in v.split(',') {
514                    spine.insert(
515                        part.parse::<usize>()
516                            .map_err(|_| format!("--spine {part}: not a node id"))?,
517                    );
518                }
519            }
520            // The transpose graph, to hang the root's ancestry on the other
521            // side of it: the hourglass of [`Part`].
522            "--ancestors" => {
523                i += 1;
524                ancestors = Some(
525                    argv.get(i).ok_or_else(|| format!("--ancestors wants a graph basename\n{USAGE}"))?,
526                );
527            }
528            flag @ ("--depth-up" | "--fanout-up" | "--max-nodes-up") => {
529                i += 1;
530                let v = argv.get(i).ok_or_else(|| format!("{flag} wants a number\n{USAGE}"))?;
531                let n = v
532                    .parse::<usize>()
533                    .ok()
534                    .filter(|&n| n > 0 || flag == "--depth-up")
535                    .ok_or_else(|| format!("{flag} {v}: not a usable number"))?;
536                match flag {
537                    "--depth-up" => depth_up = Some(n),
538                    "--fanout-up" => fanout_up = Some(n),
539                    _ => max_nodes_up = Some(n),
540                }
541            }
542            "-h" | "--help" => return Err(USAGE.to_string()),
543            other if other.starts_with('-') => {
544                return Err(format!("unknown flag {other}\n{USAGE}"))
545            }
546            other => basenames.push(other),
547        }
548        i += 1;
549    }
550
551    let [graph_name] = basenames.as_slice() else {
552        return Err(format!(
553            "expected one graph basename, got {}\n{USAGE}",
554            basenames.len()
555        ));
556    };
557    let Some(out_path) = out_path else {
558        return Err(format!("-o is required\n{USAGE}"));
559    };
560    if roots.is_empty() {
561        return Err(format!(
562            "--root is required: the whole graph is what tree-jp2 is for\n{USAGE}"
563        ));
564    }
565    if let Some(spine) = prune.expand.as_mut() {
566        // The roots expand whether or not the caller repeated them in the
567        // spine: a chain that excluded its own head would draw one node.
568        spine.extend(roots.iter().copied());
569    }
570
571    eprintln!("reading {graph_name}");
572    let graph = BvGraph::with_basename(graph_name)
573        .load()
574        .map_err(|e| format!("{graph_name}: {e:#}"))?;
575
576    let mut arena = Arena::new();
577    let sampled = forest::build_rooted(&graph, &mut arena, &roots, &prune)?;
578    eprintln!("{}", sampled.summary());
579    if ghost && !sampled.dropped_is_complete() {
580        return Err(format!(
581            "--ghost: the walk dropped {} arcs and only {} were kept, so the page would \
582             be missing arcs its caption claims; draw a smaller neighbourhood",
583            sampled.dropped_arcs,
584            sampled.dropped.len()
585        ));
586    }
587
588    let arena = forest::lay_out_oriented(arena, sampled.root, vertical);
589    let scene = Scene::of(&arena, sampled.root)?;
590    drop(arena);
591    let mut truncated = sampled.truncated;
592    // Kept only when they are going to be drawn: the walk always records
593    // them, the page need not carry them.
594    let dropped: Vec<(u32, u32)> = if ghost { sampled.dropped } else { Vec::new() };
595
596    // The other side of the hourglass: the same root walked on the transpose,
597    // under its own scissors where the caller gave any.
598    let ancestry: Option<(Scene, HashSet<usize>, Vec<(u32, u32)>)> = match ancestors {
599        None => None,
600        Some(anc_name) => {
601            let [root] = roots.as_slice() else {
602                return Err("--ancestors wants exactly one --root: the hourglass has one waist".to_string());
603            };
604            let prune_up = forest::Prune {
605                depth: depth_up.or(prune.depth),
606                max_nodes: max_nodes_up.unwrap_or(prune.max_nodes),
607                fanout: fanout_up.or(prune.fanout),
608                // A spine names descendants; the ancestor side has its own
609                // scissors and no spine to follow.
610                expand: None,
611            };
612            eprintln!("reading {anc_name}");
613            let tgraph = BvGraph::with_basename(anc_name)
614                .load()
615                .map_err(|e| format!("{anc_name}: {e:#}"))?;
616            let mut arena = Arena::new();
617            let up = forest::build_rooted(&tgraph, &mut arena, &roots, &prune_up)?;
618            eprintln!("ancestors: {}", up.summary());
619            if ghost && !up.dropped_is_complete() {
620                return Err(format!(
621                    "--ghost: the ancestor walk dropped {} arcs and only {} were kept; \
622                     draw a smaller neighbourhood",
623                    up.dropped_arcs,
624                    up.dropped.len()
625                ));
626            }
627            let arena = forest::lay_out_oriented(arena, up.root, vertical);
628            let up_scene = Scene::of(&arena, up.root)?;
629            // The root is drawn by the descendant part, so a cut on its
630            // ancestor side must reach it there or go unsaid.
631            if up.truncated.contains(root) {
632                truncated.insert(*root);
633            }
634            let up_dropped = if ghost { up.dropped } else { Vec::new() };
635            Some((up_scene, up.truncated, up_dropped))
636        }
637    };
638
639    let mut parts = vec![Part {
640        scene: &scene,
641        truncated: &truncated,
642        dropped: &dropped,
643        flipped: false,
644    }];
645    if let Some((up_scene, up_truncated, up_dropped)) = &ancestry {
646        parts.push(Part {
647            scene: up_scene,
648            truncated: up_truncated,
649            dropped: up_dropped,
650            flipped: true,
651        });
652    }
653
654    let opts = Layout { width, max_height, fill, vertical, labels, ghost };
655    let page = draw(&parts, &marks, &opts);
656    let (w, h) = (page.width(), page.height());
657    page.write(out_path)?;
658
659    let drawn = scene.len() + ancestry.as_ref().map_or(0, |(s, _, _)| s.len() - 1);
660    if ghost {
661        // Said in its own line because it is the figure's own claim: these
662        // are the arcs of the graph that the tree is not evidence for.
663        let ghosts = dropped.len() + ancestry.as_ref().map_or(0, |(_, _, d)| d.len());
664        eprintln!("{ghosts} dropped arc(s) drawn as ghosts");
665    }
666    let size = std::fs::metadata(out_path)
667        .map(|m| m.len())
668        .map_err(|e| format!("{out_path}: {e}"))?;
669    eprintln!(
670        "{} nodes on a {:.0} by {:.0} pt page, {} bytes written to {out_path}",
671        drawn, w, h, size
672    );
673    Ok(())
674}

676fn main() -> ExitCode {
677    match run() {
678        Ok(()) => ExitCode::SUCCESS,
679        Err(message) => {
680            eprintln!("{message}");
681            ExitCode::FAILURE
682        }
683    }

690    /// A scene of the forest the other binaries' tests draw, pruned or not.
691    fn scene_of(
692        n: usize,
693        arcs: &[(usize, usize)],
694        roots: &[usize],
695        prune: &forest::Prune,
696    ) -> (Scene, HashSet<usize>) {
697        let g = forest::graph_of(n, arcs);
698        let mut arena = Arena::new();
699        let sampled = forest::build_rooted(&g, &mut arena, roots, prune).unwrap();
700        let arena = forest::lay_out(arena, sampled.root);
701        (Scene::of(&arena, sampled.root).unwrap(), sampled.truncated)
702    }

707        draw(
708            &[Part { scene, truncated, dropped: &[], flipped: false }],
709            &HashSet::new(),
710            &Layout {
711                width: w,
712                max_height: h,
713                fill,
714                vertical: false,
715                labels: false,
716                ghost: false,
717            },
718        )
719    }

721    /// The deflated content stream of a written page, as text.
722    fn ops_of(page: Page, name: &str) -> String {
723        use std::io::Read;
724        let path = std::env::temp_dir()
725            .join(format!("tree-pdf-ops-{}-{name}.pdf", std::process::id()));
726        let path = path.to_string_lossy().into_owned();
727        page.write(&path).unwrap();
728        let bytes = std::fs::read(&path).unwrap();
729        std::fs::remove_file(&path).ok();
730        let start = bytes.windows(7).position(|w| w == b"stream\n").unwrap() + 7;
731        let end = bytes.windows(10).position(|w| w == b"\nendstream").unwrap();
732        let mut ops = String::new();
733        flate2::read::ZlibDecoder::new(&bytes[start..end])
734            .read_to_string(&mut ops)
735            .unwrap();
736        ops
737    }

778    /// The cut frontier is drawn in its own colour: the page of a pruned walk
779    /// names [`CUT`] where the page of the whole subtree does not.
780    #[test]
781    /// The dropped arcs are drawn only when they are asked for, in their own
782    /// ink and dashed, and the page carries as many of them as the walk said
783    /// it dropped.
784    ///
785    /// The diamond `0 -> {1, 2} -> 3` is the smallest block-shaped thing there
786    /// is: the walk hangs 3 under 1 and drops `2 -> 3`, so a ghosted page must
787    /// hold one more segment than a plain one, and `--ghost` must be what puts
788    /// it there.
789    #[test]
790    fn the_ghosts_are_drawn_and_opt_in() {
791        let arcs = [(0, 1), (0, 2), (1, 3), (2, 3)];
792        let g = forest::graph_of(4, &arcs);
793        let mut arena = Arena::new();
794        let sampled =
795            forest::build_rooted(&g, &mut arena, &[0], &forest::Prune::default()).unwrap();
796
797        assert_eq!(sampled.dropped_arcs, 1, "2 -> 3 is the second parent of 3");
798        assert_eq!(sampled.dropped, vec![(2, 3)], "and it is kept, not only counted");
799        assert!(sampled.dropped_is_complete(), "one arc is under any cap");
800
801        let dropped = sampled.dropped.clone();
802        let arena = forest::lay_out(arena, sampled.root);
803        let scene = Scene::of(&arena, sampled.root).unwrap();
804
805        let render = |dropped: &[(u32, u32)], ghost: bool, name: &str| {
806            let page = draw(
807                &[Part {
808                    scene: &scene,
809                    truncated: &sampled.truncated,
810                    dropped,
811                    flipped: false,
812                }],
813                &HashSet::new(),
814                &Layout {
815                    width: 300.0,
816                    max_height: 300.0,
817                    fill: false,
818                    vertical: false,
819                    labels: false,
820                    ghost,
821                },
822            );
823            ops_of(page, name)
824        };
825
826        // The ghost colour's operands, as `pdf::num` spells them, and the dash.
827        // The scratch names are this test's own: `ops_of` keys its temp file on
828        // them, and the suite runs its tests in one process, in parallel.
829        let plain = render(&dropped, false, "ghost-off");
830        assert!(!plain.contains("0.62 0.72 0.86"), "no ghost was asked for: {plain}");
831        assert!(!plain.contains("] 0 d"), "and so nothing is dashed: {plain}");
832
833        let ghosted = render(&dropped, true, "ghost-on");
834        assert!(ghosted.contains("0.62 0.72 0.86"), "the dropped arc is inked: {ghosted}");
835        assert!(ghosted.contains("[1.6 1.3] 0 d"), "and dashed: {ghosted}");
836        assert!(ghosted.contains("[] 0 d"), "the dash is undone before the tree: {ghosted}");
837
838        // Three tree arcs plus the one ghost, against three tree arcs alone.
839        let segments = |ops: &str| ops.matches(" l\n").count();
840        assert_eq!(segments(&plain), 3, "the tree has three arcs: {plain}");
841        assert_eq!(segments(&ghosted), 4, "the ghost is the fourth: {ghosted}");
842    }

892    /// An hourglass draws both trees about one shared root: the root's disc
893    /// appears once, every other node once, and the drawing extends to both

896    fn an_hourglass_meets_at_its_waist() {
897        // The chain 0 -> 1 -> 2 and its transpose; the waist is node 1.
898        let g = forest::graph_of(3, &[(0, 1), (1, 2)]);
899        let t = forest::graph_of(3, &[(1, 0), (2, 1)]);

904            let arena = forest::lay_out(arena, s.root);

906        };
907        let (down, down_cut) = build(&g);
908        let (up, up_cut) = build(&t);

910
911        let one_sided = page_of(&down, &down_cut, 300.0, 300.0, false);

917            Layout {
918                width: 300.0,
919                max_height: 300.0,

922                labels: false,
923                ghost: false,

926        // The width binds in both cases, so the wider drawing shows up as a
