Expand description

How many of arcs cross a row within CLEARANCE of a node or an ellipsis that is not one of their ends.

Rows are the only places anything is drawn, so an arc can only pass over something where it meets a row: at the breadth where it crosses, or, for an arc along a row, anywhere strictly between its ends. Meeting a row is found by the row’s depth, and the neighbours by binary search, so a mesh of a million arcs that each span one row costs a million lookups.
